Fonts Doodle draws with (src/app/main.odin load_a_font), first one found wins:

  mono.ttf             your own choice of monospace font: put any .ttf here with
                       this name (e.g. JetBrainsMono-Regular.ttf renamed)
  Consolas / Segoe UI  Windows' own fonts
  DejaVuSansMono.ttf   bundled, so Linux / Steam Deck always has a font
                       (DejaVu Fonts 2.37, https://dejavu-fonts.github.io;
                       free license: DejaVu-LICENSE.txt)
  DejaVu Sans Mono     from /usr/share/fonts, if installed
